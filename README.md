# 特定行為依頼窓口（依頼文作成HTML）

院内の看護師・医師が、特定看護師への相談・依頼文を作り、LINE WORKSの「特定行為依頼窓口」へ送るための単一HTMLです。

- 配布用URL：https://t07ebina-maker.github.io/LINE_WORKS_nursing-request-portal/
- 最新版：`index.html`（`index_v12.html` と同じ内容）
- 詳しい経緯・仕様・残課題は、作成者のOneDriveにある引き継ぎ書（院内の運用を含むため、このリポジトリには置かない）

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 配布用（最新版） |
| `index_v12.html` | 最新版の控え（見比べ用） |
| `chat.html` | チャット版（試作v8）。質問に順に答える形。選択肢・依頼文の書式・案内はv12と同じ。v12を直したら同じように直す |
| `archive/` | 旧版（v2〜v11、3ファイル版、3月のサンプル試行） |
| `tools/verify_v12/` | v12以降の検証（下記）。Windowsの Edge と Node だけで動く（追加インストール不要） |
| `tools/verify_v2.js` | v11までの依頼文の形の検証（v12の依頼文には使えない） |

## v12の依頼文（受け取る側の見やすさを優先）

1行目に［緊急度］、2行目に「行為／患者さんの病棟・部署」。続いて【依頼者】【行為】【依頼内容】【対象患者】【現在の状況】【その他】の見出しと内容を、空行を入れずに並べる。Excelの受付マクロはv8以降でこの形を読む（v11までの形も読める）。

## 直すときの手順

1. `index.html` を直接直さない。`index_v13.html` のように版を上げたファイルで直す。
2. 検証する（下記）。どちらも `fail 0 pageerrors 0` なら合格。
3. 確定したら `index.html` へ反映し、前の版を `archive/` へ移す（`git mv`）。

```
node tools/verify_v12/test_v12.mjs index_v13.html out.json
node tools/verify_v12/test_chat.mjs chat.html out.json
```

`test_v12.mjs` は全部の組み合わせの依頼文と画面操作を確かめ、`out.json` に書き出す。`test_chat.mjs` はその書き出しを使い、チャット版が同じ依頼文を作るかと画面操作を確かめる。

## 毎年2月にすること

春分の日・秋分の日は、国が前年2月に官報で正式に発表する。2028年以降の祝日は計算による予定日なので、毎年2月に発表と照らし合わせ、`index_vN.html` の `HOLIDAYS` と、Excelの設定シートS列の両方を直す。祝日は2031年まで入っている。

依頼文の形（見出し・項目名・改行）や依頼メニュー・行為の分け方を変えると、Excelの受付マクロで読めなくなる。形を変えたら、上の検証に加えて、Excel本体（統合版v8.xlsm）でも1件以上登録を確かめる。

## 守ること

- 患者情報を含むファイル（実運用のExcelなど）はリポジトリに入れない。テストは合成データだけ。
- 引き継ぎ書・仕様書など院内の運用を書いた文書もリポジトリに入れない（公開リポジトリのため）。
- 外部通信・データ送信を加えない（院内で使う前提。依頼者の氏名・所属・連絡先の端末記憶だけ任意で使う）。
- Excel（受付・集計・評価 統合版v8.xlsm）はリポジトリの外（作成者のOneDrive）にある。クラウド環境からは見えないので、Excel側の確認が必要な変更は、ローカルで行う。
